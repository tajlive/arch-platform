Recruiter / Engineering Tour

En 2–3 minutt guidet gjennomgang: Problem → Arkitektur → AI-agenter → Governance → Security → Observability → Evals → Produksjonsbevis.

Guided Tour

  1. 1. Problem

    Bedrifter vet ikke hva de bør automatisere. Intervjuer gir anekdotisk evidens. Systemdata gir noe annet. Arch bruker evidens til å finne verdien.

  2. 2. Arkitektur

    Cloudflare Workers + D1 + R2 + AI Gateway. Én plattform. Application-layer tenant isolation. Deterministisk ROI-engine. Evidence-first metodikk (E0–E4).

  3. 3. AI-agenter

    Orkestrert av Hermes (Chief Architect). 6 spesialiserte agenter: Discovery, Evidence, Process, Automation, Risk, Critic. Hver med definert autonomi (A0–A5) og policy-enforced tool permissions.

  4. 4. Governance

    Policy-as-code (OPA/Rego). Runtime enforcement + CI/CD gates. Audit trail på alle beslutninger. Human-in-the-loop for HIGH/CRITICAL risiko.

  5. 5. Security

    Zero-trust. Application-layer tenant isolation (D1 RLS via middleware, R2 prefix, Workers middleware). Cloudflare Access + OIDC. Cross-tenant attack testing (18/18 grønne).

  6. 6. Observability

    Cloudflare AI Gateway (tokens, cost, latency) + OpenTelemetry export. Full trace: User → Orchestrator → Agent → Model → Tool → Policy → Evidence → Decision.

  7. 7. Evals

    Golden cases (12 scenarier). Regression gate (95% threshold). Extraction F1 > 90%, Classification > 85%, Grounding 100%, Hallucination < 2%.

  8. 8. Produksjonsbevis

    Live CI: 487 tests passed. Cross-tenant tests: 18/18 grønne. Deploy gates: 12/12 grønne. Production verified på arch.axn.no.
