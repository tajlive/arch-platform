# Arch Audit Free vs Paid Boundary

**Dato:** 2026-08-20

---

## FREE (gratis, ingen konto)

| Gir | Beskrivelse |
|-----|-------------|
| Company X-Ray | Public signals (Brønnøysund, nettside, roller) |
| Offentlige signaler | 18+ signals med confidence |
| Maks 3 funn | evidence-baserte, med kilde |
| Confidence | per signal + samlet |
| Mulige områder | teaser («Customer operations», «Reporting») |
| INSUFFICIENT EVIDENCE | ærlig når data mangler |

## FULL AUDIT (betalt)

| Gir | Beskrivelse |
|-----|-------------|
| Interne data | dokumenter, prosesser, metrics |
| Systemanalyse | ERP, CRM, connectors |
| Prosesskart | full process/task map |
| Deterministic ROI | LOW/EXPECTED/HIGH med auditerbar input |
| Risk analysis | risiko + mitigering |
| Integration architecture | systemintegrasjoner |
| Prioritized roadmap | implementeringsplan |
| Executive report | full rapport |

## Prinsipp

> **Begrens scope, ikke intelligens.** Gratisversjonen bruker samme LLM og Question Intelligence. Den gir bare færre resultater (3 funn vs full analyse). Ingen kunstig «96 % ferdig — betal»-gimmick.

## Free boundary-trigger

Når Arch har demonstrert verdi (nok funn + evidens), IKKE etter tilfeldig token/melding-grense.
