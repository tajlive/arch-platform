# ADR-011 — Free Value Boundary

**Status:** ACCEPTED  
**Dato:** 2026-08-20

## Context

Arch må gi gratisverdi (demonstrere intelligens) uten å gi bort produktet (full audit).

## Decision

**Gratis (Public X-Ray):**
- Public signals (18 signals, confidence, potential areas)
- 1–3 visible findings med evidens
- Indikativ ROI (range, merk «INDICATIVE»)

**Premium (Full Audit):**
- Full prosesskart + task map
- Complete evidence graph
- Deterministic ROI (LOW/EXPECTED/HIGH)
- Risk analysis, integration architecture, prioritized roadmap
- Executive report

## Konsekvenser

- Free boundary = scope, IKKE svekket modell. Samme LLM, færre resultater.
- Ingen kunstig «96 % ferdig — betal»-gimmick. Gratisgrensen settes ved faktisk demonstrert verdi.
